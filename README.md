# Трекер развивающих игр (PWA)

Приложение для ежедневной отметки занятий с ребёнком: список игр с категориями
и статусами, журнал «во что играли» по дням, сводка по категориям.

## Использование на iPhone

1. Откройте **https://tsybriki.github.io/kid-games-tracker/** в Safari.
2. Нажмите «Поделиться» → «На экран „Домой“».
3. Приложение появится отдельной иконкой и откроется без адресной строки.

> В iOS нельзя установить PWA из Chrome — только из Safari.

## Что внутри

**Игры** — все 54 занятия, сгруппированные по 11 категориям. У каждого занятия
статус (Готово / Доделать / Подготовить / Играет редко / Освоено, легко).

Чтобы отметить игру:
- тап по занятию → «Отметить как сыгранное» → поле «Что получилось»;
- или тап по кружку справа в списке (отметка ставится/снимается).

**Журнал** — по дням: что играли и что получилось. Фильтры: 7 дней / 30 дней / всё.

**Сводка** — сколько игр за 7 дней, сколько разных игр сыграно, полоски по категориям.

**Расширение** — «＋» в шапке добавляет занятие (с выбором категории и статуса),
«＋ Новая категория» в «Сводке» добавляет категорию с цветом. Занятие можно
переименовать и удалить из его карточки.

## Данные

Всё хранится в `localStorage` браузера — только на этом устройстве, без сервера
и без аккаунта. **Перед очисткой Safari или сменой телефона** нажмите
«Экспорт данных (JSON)» в «Сводке» и сохраните файл. Импорт — кнопкой рядом.

Кнопка «Сбросить всё» возвращает исходный список из 54 занятий.

## Разработка

Статика, без сборки. Любой HTTP-сервер:

```bash
python3 -m http.server 8765
```

### Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Разметка трёх вкладок и трёх шторок |
| `styles.css` | Дизайн-система, адаптив под мобильный |
| `app.js` | Логика: состояние, рендер, localStorage, импорт/экспорт |
| `seed.js` | Исходные 54 занятия и 11 категорий |
| `sw.js` | Service worker: офлайн-режим |
| `manifest.webmanifest` | Манифест PWA |
| `icons/` | Иконки 192/512/maskable + apple-touch-icon |

### Деплой

```bash
git push origin master   # GitHub Pages, ветка master
```

При изменении `sw.js` нужно поднять версию кэша `CACHE` в его начале, иначе
браузер продолжит отдавать старый кэш.
